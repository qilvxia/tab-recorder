## 1. 产品概述

**一句话**：Chrome 扩展（Manifest V3），录制**当前标签页**的画面与声音；对连播课程页面可自动跟随课时切换，把整门课按课时**分节保存**为多个视频文件，文件名=课时标题，平铺保存在浏览器默认下载目录。

**背景与目标用户**：付费在线课程学员。课程平台（典型：路飞学城，保利威加密播放器）禁用视频下载，录制是学员留存已购内容的唯一合规手段；此外覆盖两类常见免费场景：B 站多 P 视频、YouTube 播放列表。产品只录制用户有权观看的内容，用户须自行遵守网站服务条款（商店描述中保留此提示）。

**三类典型场景**（重写验收时必须全部对齐）：

| 场景 | 特征 | 产品应对 |
|---|---|---|
| 路飞学城类课程站 | 播放器画面/声音对页面脚本不可见（加密），播完弹出「放弃评价观看下一节」弹窗，SPA 切课 URL 常不变 | 「播放信号盲区站」：靠弹窗入口可见性切节+自动点击连播；暂停/收尾不自动停止（见 F7） |
| B 站多 P | 同页换集 URL `p=` 变化，mediasession 恒为合集总标题 | 「URL 变化即切节」选项 + 备选课时名通道（目录高亮分集名） |
| YouTube 播放列表 | 播放中 URL `t=` 进度参数周期变化，自带连播 | URL 指纹剥进度参数防碎切；不自动点击（站点自带连播，双推进会跳课） |

**产品形态**：弹窗控制面板（唯一交互面）+ 工具栏徽章（唯一状态指示）。无后台服务器、无账号体系、全部数据本地处理。

**技术形态约束**：Chrome MV3 扩展；零构建 vanilla JS/HTML/CSS（产物即上架包，无打包链路）；最低 Chrome 116。

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 信号可见站 | 页面 video 的 playing/ended 事件与状态对内容脚本可见的站点（B 站、YouTube） |
| 盲区站 | 加密播放器站点：页面上的 video 是空壳（paused=true、currentTime=0、尺寸 0×0），加密画面不经它渲染，playing/ended 永不可见（路飞学城/保利威） |
| 黑白名单 | 无手动名单的自动分档：本会场曾收到过任一次播放信号 → 白名单（信号可见站，收工按倒计时执行）；从未收到 → 黑名单（盲区站，时间型自动收工整段不适用） |
| 切节 | 分节录制中，把当前课时录制收尾保存、随后为新课时开新段的动作 |
| between（节间） | 切节后、下一节恢复录制前的等待态；捕获流保持活跃，节间画面不录制 |
| 锚点直存 | 唯一保存通道：offscreen 文档内 `File([blob], name)` + `<a download>` 点击触发浏览器下载，后台按文件名轮询下载完成做回执（见 TDD 红线 R1） |
| 确定性切分点 | 连播点击成功时刻——旧节尚在播、新节未开播，此刻停录保存使新旧节尾部干净 |
| URL 指纹 | URL 剥除进度类参数（t/t2/time/start/progress/at/ts/timestamp）与 hash 后的 origin+pathname+search；指纹不变=仅进度更新，非换内容 |
| 课时名 | 当前正在播放课时的标题；由多来源识别并竞争裁决（见 F3） |
| SRC_RANK | 课时名来源可信度六级：mediasession(6) > selector(5) > active-item(4) > playing-label(3) > video-title(2) > doc-title(1) |

## 3. 功能需求

约定：【验收】小节为可判定的验收标准；括号内数字为实现对齐值，重写不得擅改（调整须回写本文档）。

### F1 单段录制

**需求**：把当前标签页录成一个视频文件。

行为规格：
- 模式二选一：单段录制 / 自动分节（连播课程）；选择持久记忆。
- 延时开始：0–60 秒可设（默认 0）；延时期面板与徽章显示剩余秒数，可取消。
- 文件名：用户手填（可选，全局记忆）> 页面识别标题 > 兜底 `录制_YYYYMMDD-HHMMSS`；非法字符清洗、Windows 保留名防护（CON 等）。
- 暂停/继续；停止并保存；**停止不保存**（丢弃当前未保存内容，二次确认：首点按钮变「确认丢弃？」，3 秒未点恢复；已落盘的历史节不受影响）。
- 自动停止双通道（默认启用，无开关）：
  - 停播停止：页面停止播放持续 5 秒（信号可见站）→ 自动结束（原因 video-stopped）；
  - ended 停止：收到播放器 ended 事件锁存 5 秒（期间恢复播放则解除——分片播放器的假 ended）→ 自动结束（video-ended）。信号盲区站靠此通道兜底。
- 输出格式 MP4（H.264+AAC）。

【验收】延时倒计时准确归零后开始；暂停不计时（总时长=有效录制时长）；手填名生效；播完 5 秒内自动停止保存；停止不保存后下载目录无本次文件；自动停止原因在面板可见。

### F2 分节连播录制（核心）

**需求**：课程页面连播时，每节课自动切成一个文件，文件名=课时标题，全程无需人工干预。

行为规格：
- 课程名前缀（可选，按站点记忆）：非空时文件名=`前缀_两位节序-课时名`；空时=`两位节序-课时名`。
- 自动分节：页面内容更换信号（见 F3/F4 与 TDD 信号体系）触发切节；全局最小切节间隔 10 秒，间隔未到的信号**挂起重试不丢弃**。
- 切节采用「节间停止-恢复」：停录并保存当前节 → 等待下一节就绪（保持捕获流活跃，零丢帧）→ 同流开新 recorder 续录。节间黑屏/加载画面不入文件。
- 确定性切分：自动连播点击成功的瞬间即停录保存旧节（新节尚未开播，尾部零污染），节间随即恢复续录。
- 自动连播点击（可关，默认开）：检测「下一节」类入口并点击。入口三方式并存：①可见文本词表（下一节/下一课/下一集/下一讲/下一章/下一个/继续观看/观看下一/播放下一）；②class 启发式（next/skip/close/continue）；③高亮目录项的下一项。点击带完整鼠标事件序列（pointerdown→mousedown→mouseup→click）；http(s) 链接同页跳转防断录制。点击冷却 15 秒跨帧共享（防「下一节」被点两次跳课）。连播失效兜底：每 45 秒重发一次点击指令。
- 节间恢复源五路先到先得：①连播点击成功；②弹窗入口消失（含手动点掉）；③页面恢复播放；④URL 稳定 3 秒；⑤节间超时 30 秒。
- 碎片防护：段内容不足 2MB（约数秒）不允许切节（启动识别期/抖动期的小段直接并入后续内容）；课时名变化但当前段不足 4MB（约 8 秒）时只改名不切节。
- 小段黑屏丢弃：切节后首个短段（<2MB）丢弃且节序号不跳。

【验收】三节连播课程自动产出三个文件；节序连续；文件名与课时一一对应；连播弹窗被自动关闭；整场无碎片段；新节开头零丢失（可含 1–3 秒加载画面，属内容完整优先的既有取舍）。

### F3 播放标题识别（课时名）

**需求**：在任意课程/视频站点识别「当前正在播放的课时标题」用于命名，不针对特定站点硬编码。

行为规格：
- 多来源级联识别，按 SRC_RANK 竞争裁决：mediasession 媒体元数据(6) > 页面主选择器 h1(5) > 目录高亮项(4) > 「正在播放：」文字标签(3) > video 标题属性(2) > 页面标题剥尾巴(1)。
- 帧内备选通道：主值与「目录高亮项」并行采集上报（B 站 mediasession 恒为合集总标题，分集名只经备选通道到达），由低阶来源稳定 2 秒接管命名；高阶来源后续真实变化仍可夺回。
- 来源竞争语义：同名上报忽略；低阶来源稳定 2 秒且高阶值未变 → 接管；高阶来源值变化且与现有段名**相关**（互相包含）→ 改写；**互不包含（在说不同的事）→ 不改写**；同源值变化=真换课。
- 杂音过滤：标题长度 2–80；拒绝 UUID/长十六进制/长纯数字；拒绝分隔符堆叠（`--`/`——`/`~~`）、目录统计词（「N 个课时」等）、加载词（「正在加载/请稍后」）；目录项命中排除通用界面词（首页/课程/目录/播放/全屏/返回/上一节/下一节 等 25 词）。
- 目录高亮项识别加强：容器型命中跳过（含多个子条目的元素是列表不是当前项）；播放器控件菜单内的「当前清晰度」类高亮不算课时；命中项优先取内部 title 类子元素的纯文本，兜底整项文本并剥尾部时长。
- 识别失败：文件名回落为「第N节」；后续识别到位自动补写段名。

【验收】B 站多 P：每个文件=分集名（非合集总标题）；路飞：文件名随切课变化；「识别诊断」按钮（F8）可在任意站点输出各级来源命中明细。

### F4 分节方式选项

**需求**：站点差异由用户标注，两模式叠加不替换。

- **智能模式**（默认）：按页面课时名语义切节；URL 仅作联动确认（真换课=课时名与 URL 都变过），进度参数抖动不切。
- **URL 模式**（勾选「网址一变就切下一节」）：URL **指纹**变化即切（B 站多 P/YouTube 换集同页场景）。防碎切：进度参数剥除（YouTube 播放中每约 10 秒更新 `&t=` 不得触发）；URL 变化瞬间暂停编码器（URL 刹车），旧节尾部零污染，切分完成后续录。

【验收】默认模式对路飞零回归；URL 模式下 B 站切 P 每集一文件、YouTube 播放中零碎切。

### F5 区域裁剪

**需求**：只录制页面中所选矩形区域。

- 高级设置内「框选区域…」：页面上拖拽框选（Shadow DOM 浮层），支持比例锁定（自由/16:9/4:3/1:1），双击确认、Esc 取消、最小 40×30；选区绑定当前标签页，换标签页失效，跨录制保留可清除。
- 裁剪数学（单一广义黑边定律，v2.8.16 定稿）：Chrome 把窗口画面**等比缩放+居中补黑边**放进捕获帧（黑边是 Chrome 的行为，用户实测实锤：窗口化场景帧 2240×1400 装视口 1494×773，上下黑边各 ~120px）；映射反算补偿——`scale=min(帧宽/视口宽, 帧高/视口高)`，采样点加对应方向黑边 offset。输出=所选区域的精确内容（无黑边无变形，纵横比随选区）。输出尺寸向下取偶（H.264 要求）；换算后 <16px 报错并降级全画面（面板可见降级原因）。
- 漂移提示：当前视口与框选快照不一致时面板警告「建议重新框选」（仅提示不阻断）。

【验收】中心 50% 选区参照线误差 ≤2px；B 站/路飞/最大化窗口正确；**已知限制如实保留**：YouTube 窗口化场景 Chrome 帧协商异常导致的残余偏移不处理（用户已决定放弃，见 TDD 平台事实 P7）。

### F6 录制内容与参数

- 内容三选：音视频（默认）/ 仅视频 / 仅音频（仅音频输出 .webm）。
- 高级参数：视频码率 1–50 Mbps（默认 4）、帧率 5–60（默认 30）、音频码率 32–320 kbps（默认 128）。
- 仅视频时页面声音仍照常播放给用户（录制不劫持听觉）。

【验收】三选均产出正确轨道组合；参数变更即时生效到下一段。

### F7 自动停止四件（分节模式）

| 通道 | 触发 | 行为 |
|---|---|---|
| 定时停止 | 有效录制时长（暂停/节间不计）达到设定值（不限/自定义 HH:MM:SS） | 结束并保存，原因 preset |
| 无播放收工 | 用户设收工秒数（默认 60，0=关）：**白名单站**（本会场出现过播放信号）在「续录后从未在播」持续超过设定值 → 结束；**黑名单站**（从未收到播放信号=盲区站）**时间型自动收工不适用**——面板常显「信号盲区：播放/暂停不可检测，请手动停止（可改用定时停止）」 | idle-wrap / blocked 提示 |
| 停播切段 | 页面停止播放 5 秒（白名单站）→ 切节进节间，等恢复或收工 | advance-pause |
| 入口可见切段 | 播完弹窗持续可见 3 秒且段 ≥2MB（盲区站主通道）→ 切节进节间 | entry-visible |

收工语义定稿说明（重写不得回退）：盲区站「下一节正常播放」与「暂停/卡死」在其可见信号上**数学不可区分**，任何固定时间窗口必误杀其一——历史 v2.8.4~v2.8.12 的每个窗口版本都曾在切下一节后误杀正常播放，v2.8.14 起盲区站彻底取消时间型收工。代价（已知且被用户接受）：盲区站暂停/课程播完后录制持续，需手动停止或用定时停止兜底。

【验收】信号可见站（B 站）暂停后，倒计时走满设定值精确收工（误差 <1 秒），无碎片段；路飞整场连录切节后**永不**自动停止、面板常显盲区提示；定时停止不受暂停/节间影响（按时长不按挂钟）。

### F8 面板设置记忆 + 识别诊断

- 设置记忆（storage.local）：模式选择、课程名（**按站点 hostname 键控**：当前站点恢复上次填写，无记录预填域名）、单段手填文件名（全局单值）、定时停止模式与时长、内容三选、码率/帧率/音频、延时、收工秒数、自动连播、URL 模式。
- 「识别诊断」按钮（待机区即可用）：向当前页所有帧采集——video 清单（paused/ended/currentTime/时长/尺寸/可视面积/祖先链）+ currentTime 间隔 2 秒双采样推进标注（播放铁证）+ 播放器播放/暂停按钮 + mediaSession.playbackState + 本扩展检测器视角（在否/判定值/当前课时名）——汇总 JSON 复制到剪贴板。用于任意站点「为什么不识别/为什么不收工」的一次性取证。

【验收】重开面板各项保持上次选择；跨站点课程名互不串扰；诊断 JSON 能回答「检测器是否活着、哪个来源命中了什么、视频是否真在推进」。

### F9 状态面（面板 + 徽章）

- 徽章六态：倒计时数字 / `‖` 节间 / `REC` 录制 / `II` 暂停 / `···` 收尾 / 空。
- 面板录制区实时显示：当前课时名与识别来源、节序、本节时长/总时长/总大小、暂停继续/停止保存/停止不保存、「上次切节」原因与时刻、收工倒计时或阻塞原因（独立行）、待确认课时名、裁剪状态与降级原因、捕获帧/视口数字与漂移警告、最近 URL 变化观测、连播点击日志（最近 5 条）、错误行。
- 不自动弹出任何窗口（历史教训：windows.create 使弹窗失焦秒关）；一切状态经徽章+面板传达。

【验收】录制全程用户不看开发者工具即可判断「卡在哪一环」（切节原因/连播日志/收工状态/识别来源全部可见）。

## 4. 非功能需求

1. **零数据收集**：无任何网络上传；不请求 host 权限；不读取与录制无关的数据。商店隐私声明如实（附录 A）。
2. **权限最小化**：仅 `tabCapture, offscreen, downloads, storage, scripting, activeTab` 六项；内容脚本全部动态按需注入（manifest 无 content_scripts 静态声明）；activeTab 仅在用户点击扩展时临时授予当前页。
3. **离线可用**：不依赖任何远程资源。
4. **稳健性**：录制中标签页关闭/扩展重载/下载超时（5 分钟上限）等异常路径均有收尾，不悬空「保存中」状态；扩展重载后页面无需刷新即可恢复检测（死实例自清+新实例可重建）。
5. **时长语义**：一切计时（定时停止/延时）基于有效录制时长，暂停与节间不计入。

## 5. 明确不做（非目标）

- 跨浏览器（Firefox/Safari）；产品只对 Chrome（≥116）负责。
- 云端存储/转码/账号；下载（而非录制）平台视频——包括任何绕过 DRM/加密的手段。
- 视频编辑（剪辑/合并）；MP4 duration=0 是 Chrome 直录已知行为，修复交给外部 ffmpeg，产品不做。
- 后台/多标签页同时录制；摄像头/麦克风采集；屏幕窗口级采集（仅标签页）。
- 针对特定站点的硬编码适配（一切站点行为走通用信号，用户以选项标注差异）。

## 6. 已知限制（如实随产品交付，不得隐瞒或偷偷「修」）

1. 盲区站（路飞类）暂停或整门课播完后不会自动停止——设计定稿（F7），手动停止或定时停止兜底。
2. 盲区站暂停收工场景会保存一个节间超时恢复→收工之间的静止画面尾段文件（节间超时兜底的既有产物语义）。
3. 切节续录的新节开头可能含 1–3 秒加载画面（内容完整优先于画面纯净的取舍）。
4. B 站个别切 P 尾部几秒可能含下一集开头（URL 刹车已尽量消除，残余接受）。
5. MP4 直录 duration=0（Chrome 平台行为）。
6. YouTube 窗口化（非最大化）录制时裁剪可能偏移——Chrome 帧协商平台行为，用户已决定放弃处理。
7. 窗口被完全遮挡/最小化时画面冻结、声音正常（浏览器省电机制）。
8. 自动连播点击依赖入口元素可发现（文本/class/列表下一项三方式覆盖不到的站点，连播退化为人手点，录制分节仍正常）。
