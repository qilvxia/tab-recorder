# v2.2.6：修复开录碎片段（URL 切段前置条件）+ 连播点击无效（javascript: 伪协议分支）

## 坏消息 1：开录 4 秒碎片段

根因：点播放动作使播放器给 URL 加参数 → URL 稳定 3 秒 → 切段；现有"同课时名不切"闸要求段名非空——开录头几秒识别未完成（段名空），闸失效。
修复：**URL 稳定切段加前置条件 currentLesson 非空**——课时名未识别时 URL 变化一律不切段（切了也无法正确命名；识别到位后段名自然补写）。换课场景段名非空不受影响。

## 坏消息 2：连播卡弹窗

根因：v2.2.2 扫描扩展到全部元素后，`javascript:` 伪协议 href 的 `<a>` 入口（评分弹窗按钮的常见实现）走 `location.href = "javascript:..."` 分支——无效操作，等于没点。
修复（content-detect 点击策略）：
- `<a>` 且 href 为 http(s)：`location.href = el.href` 同页跳转（**无论 target 是否 _blank 都强制同页**，防开新标签页断录制）
- `<a>` href 为 javascript:/空、或非 a 元素：一律 `el.click()`（冒泡给委托容器）
