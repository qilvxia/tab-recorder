## 设计原则（平台知识 → 设计约束，源自 v1 踩坑实录）

1. **保存层**：offscreen 内 `File([blob], name)` + `<a download>` 点击，唯一路径；无探测试错/通道记忆/降级链/弃用清理——v1 后期所有竞态 bug 的根源整体消失
2. **落定检测**：锚点名完全可控（含序号/时间戳），SW 用 `downloads.search({filenameRegex})` 轮询至 complete → 发回执 → offscreen 收齐后关文档（防大文件截断，语义同旧版但实现大减）
3. **识别层照搬已验证设计**：七级级联 + 垃圾名过滤 + allFrames 注入 + 初始注入重试 3 次 + detect-config 强制上报 + 6s 心跳补注入（弹窗打开时跳过）
4. **裁剪照搬**：letterbox 定律换算 + 选区浮层（M3 迁移）
5. **面板秒关**：v2 无任何开窗/气泡放大器；点开始后若面板仍关属 Chrome 录制指示 UI（平台行为），状态看徽章（倒计时/REC/保存中保留）——M1 验收时一并观察记录
6. 权限集不变（tabCapture/offscreen/downloads/storage/scripting/activeTab）；零数据收集红线不变
