# v2.2.2：切节原因可见化 + 信号全面收紧 + 连播委托点击修复

## 现状推理（URL 稳定期无效后的排除法）

剩余嫌疑信号：① lesson-change（无稳定期；弹窗期识别源抖动）② silence-gap（audible 抖动）。连播失效嫌疑：评分弹窗入口是 div/span+事件委托，现有扫描器（a/button/[role]/[onclick]）扫不到。

## 修复内容

### offscreen.js
1. **切节原因可见化（诊断）**：记录 `lastSplitInfo = {reason, time}`，status() 暴露；面板 recTip 显示「上次切节：原因 HH:MM:SS」——你复验时直接读，一次定位真凶
2. **全局最小切节间隔 10s**：doSplit 硬闸（`now() - lastSplitAt < 10000` 直接拒绝）——无论哪个信号抖动，切节频率被硬限制；换课间隔通常远大于 10s，无损
3. **lesson-change 加 2 秒稳定期**：与 URL 同模式（变化挂起，稳定才切）——滤掉识别源抖动，真换课标题会稳定
4. **静默切节后 15s 冷却**：静默切节后 15 秒内忽略一切新切节请求（与 10s 全局闸互补）

### content-detect.js（连播修复）
5. **文本扫描扩展到全部可见元素**（span/div/li/label/p 等叶子文本），不再限于 a/button/[role]/[onclick]——事件委托场景（容器监听、子元素无 handler）通过 el.click() 冒泡触发；匹配词表/长度限制不变
6. 连播尝试日志保持（[tabrec] 前缀）
