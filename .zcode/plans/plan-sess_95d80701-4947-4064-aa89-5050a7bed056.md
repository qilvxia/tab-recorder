# v2.3.1：ended 挂起——停播 5 秒统一切节（不依赖时长）

## 根因（完整机制）

该站分片播放：每个媒体分片播完触发 video ended → 当前代码「ended → 立即 stopAll 保存」不等确认 → 每分片切一段（8 段），节间广播点击“未找到入口”（弹窗不存在），视频恢复播放（下一分片）后立即续录 → 循环。

## 修复：ended 挂起，停播 5 秒统一切节

1. **onContent ended 分支移除立即 stopAll**——播完信号交由已有的停播判定处理：
   - 分片假 ended：视频 5 秒内恢复播放 → lastPlayingTs 刷新 → 5 秒计数重置 → **不切** ✓
   - 真播完：页面持续无播放 ≥5 秒 → stoppedPlayingCheck 切段保存 + broadcast 点击弹窗 ✓（该站弹窗 0.8 秒即出现，5 秒后点击无碍）
   - 无弹窗站点真播完（YouTube 连播关闭等）：停播 5 秒 → 切段 → between 等待 → 用户点下一节 → playing → 续录 ✓
2. **时长守卫方案作废**（用户指出录制时长 vs 总时长受网络/暂停干扰；本方案不依赖时长）
3. video-ended 切节原因不再出现（正常）；e2e 回归（e2e 页有真 ended——挂起后由停播判定切节，时序后移但不缺失）
