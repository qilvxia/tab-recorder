# 标签页录制器（Tab Recorder）v2

录制**当前标签页**的画面与声音的 Chrome 扩展（MV3）。v2 是按里程碑重建的版本：保存层只走「锚点直存」（在你的 Chrome 上实测文件名 100% 正确），交互只保留弹窗面板 + 工具栏徽章。

- ✅ **只录这一个标签页**——其他应用的声音绝不会混入
- ✅ **后台持续录制**——点开始后可关掉弹窗、切换标签页
- ✅ **自动命名**——识别播放器正在播放的标题（多来源级联），文件以课时标题命名，平铺保存在浏览器下载目录
- ✅ **延时开始 / 自动停止**（开发路线图见 AGENTS.md 当前状态）
- ✅ **区域裁剪 / 自动分节**（里程碑 M3/M2 逐个交付）

> v1.x 完整归档见 [legacy-v1/](legacy-v1/)（含全部历史文档与技术侦察档案）。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions` → 右上角开启**开发者模式**
2. 点 **加载已解压的扩展程序** → 选择本项目的 `extension/` 目录
3. 工具栏出现扩展图标即安装成功（建议固定到工具栏）

## 使用

1. 打开要录制的网页（普通网页即可，`chrome://` 等内置页面不能录）
2. 点扩展图标 → 可选设置**延时开始**秒数 → **开始录制**
3. 工具栏图标显示倒计时 / REC 徽章；点图标可暂停/停止
4. 录制结束后文件自动以课时标题命名，保存在浏览器**下载目录**

**重要**：请在浏览器 设置 → 下载 中关闭「下载前询问每个文件的保存位置」，保证全程静默保存。仅限录制你有权观看的内容，请遵守所访问网站的服务条款。

## 已知限制

- 文件平铺保存在下载目录（无子目录归档）——这是「文件名 100% 正确」的取舍（详见 AGENTS.md 保存层设计）
- 窗口被完全遮挡/最小化时画面冻结、声音正常（浏览器省电机制）；可用 legacy-v1/启动录制专用Chrome.bat
- MP4 直录个别播放器进度条时长显示为 0（Chrome 已知行为，用 ffmpeg `-c copy` 重封装可修）
