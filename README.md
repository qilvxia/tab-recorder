# 标签页录制器（Tab Recorder）· 自动分节版

录制**当前标签页**的画面与声音的 Chrome 扩展（MV3）。核心特性：

- ✅ **只录这一个标签页**——其他应用的声音（音乐、聊天提示音）绝不会混入
- ✅ **后台持续录制**——点开始后可以关掉弹窗、切换标签页、正常使用电脑
- ✅ **自动分节**——整门课连播时，自动检测换课时机，按课时切段、自动命名、归档到课程目录
- ✅ **录制区域裁剪**——在页面上直接框选区域（可锁 16:9 / 4:3 / 1:1），只录播放器画面不录网页杂项
- ✅ **播放标题自动识别**——多来源智能识别当前播放内容名（媒体元数据/高亮目录项/视频属性等多级兜底），用于命名与分节
- ✅ **延时开始**——点开始后倒计时 0-60 秒再录，留时间切到播放页
- ✅ **定时自动停止**（不限 / 自定义 00:00:00）/ 视频播完自动停止 / 页面静默自动停止
- ✅ 参数全部可配置：格式（MP4/WebM）、码率、帧率、命名规则、检测灵敏度

> 项目缘起与"为什么用录制而不是下载"：见 [docs/luffycity-recon.md](docs/luffycity-recon.md)。
> 仅限录制你有权观看的内容、自用学习，请遵守所访问网站的服务条款。

## 一、安装（开发者模式加载，一次性）

> 注：Chrome 稳定版已禁用命令行 `--load-extension` 自动加载，手动加载即可，配置会一直保留。

1. 打开 Chrome，访问 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目的 `extension/` 目录
4. 工具栏出现红色 REC 图标即安装成功（建议固定到工具栏）

## 二、基本使用（单段录制）

1. 打开要录制的网页（普通网页即可，`chrome://` 等内置页面不能录）
2. 点扩展图标 → 选 **单段录制** → 可选填**录制文件名**（留空自动命名）→ 可选**延时开始**（0-60 秒，点开始后倒计时，利用间隙切到播放页）→ 可选自动停止（不限 / 自定义 `00:00:00` 时长）→ **开始录制**
3. 录制中可以关闭弹窗、切换标签页、正常用电脑；点图标可查看进度/暂停/停止
4. 文件自动保存到设置中配置的**保存位置**（默认 `下载/TabRecorder/`，可在设置页改为任意本地目录）

## 三、批量录课（自动分节模式）

适用场景：网课站点整门课**自动连播**（一节播完自动播下一节），要一次录完几十上百节。

1. 打开课程播放页，让课程开始连播
2. 点扩展图标 → 选 **自动分节（连播课程）** → 填写 **课程目录名**（如"2025JS逆向"）→ 开始录制
3. 之后无需人工干预：换课时自动切段，每节课存成一个文件（以默认下载目录模式为例）：
   ```
   下载/TabRecorder/2025JS逆向/
     ├── 01-软件开发架构01.mp4
     ├── 02-软件开发架构02.mp4
     └── 03-http协议初识.mp4
   ```
   自定义目录模式下则是 `所选目录/2025JS逆向/01-….mp4`（直达所选目录，不叠子目录层）。
4. 课程全部放完（页面长时间静默）后可在设置中开启**静默自动停止**（如 60 秒），整场录制自动收工

**分节检测原理**（三重信号，去抖合并，无需针对某网站定制）：

| 信号 | 覆盖场景 |
|---|---|
| 页面 video 元素播完 | 绝大多数视频网站 |
| 页面网址变化 | 单页应用类网课（切课时路由变化） |
| 页面静默 ≥ N 秒 | canvas/加密播放器（如保利威） |

课时名的获取优先级：**播放器媒体元数据（MediaSession"正在播放"标题）→ 页面 h1（可配选择器）**。自动分节时标题变化也会触发切段，识别结果在录制面板实时可见。若两者都取不到（个别站点不放元数据、标题是内部 ID），用 F12 定位课时名元素：右键页面上的课时名 → 检查 → 在元素面板右键该节点 → 复制 → selector 选择器路径，填到设置页"课时名元素选择器"。文件名前缀/后缀可用设置里的正则与模板微调。

## 四、录制区域裁剪与播放标题识别

**只录画面中的一块区域**：弹出面板 →「录制区域」→ **框选区域…**，页面上会出现半透明遮罩，拖出想要的范围（工具条可锁 16:9 / 4:3 / 1:1 比例），回车或双击确认后开始录制，输出视频就只含该区域（输出分辨率 = 选区实际像素）。适合只录播放器画面、去掉网页侧栏与弹窗。会话内选区会保留，换课重录不用重框；点「清除」恢复全画面。

- 裁剪在录制管线内实时完成（canvas 合成流），不引入任何外部依赖，格式/码率/分节等功能照常可用
- 裁剪坐标映射已按真实采集帧校准（`scripts/diag_crop.py` 实测：浏览器采集帧与页面视口纵横比不一致时会上下补黑边，扩展已自动补偿），框选即所得，误差 ≤ 2 像素
- 已知限制：选区固定在**视口坐标**上——框选后改变窗口大小或缩放比例会让选区漂移；页面滚动时录到的是视口同一位置的内容（与 OBS 区域录制同理）。建议框选后就别动窗口布局

**输出位置**：所有文件保存在**浏览器下载目录**（默认 `下载/TabRecorder/`，子目录可在设置页改）。若保存时弹出系统"另存为"窗口，请到浏览器 设置 → 下载，关闭「**下载前询问每个文件的保存位置**」——该设置由浏览器管辖，扩展无法覆盖，关闭后即全程静默保存。

**播放标题识别（多来源级联，按顺序取第一个有效值）**：

| 优先级 | 来源 | 覆盖场景 |
|---|---|---|
| 1 | 播放器媒体元数据（MediaSession） | 保利威等标准播放器（含 iframe 内播放器，已全帧注入） |
| 2 | 课时名选择器（设置页可配，默认 h1） | 站点结构清晰、人工指定 |
| 3 | 高亮目录项（active/current/on/playing 类名的侧边栏条目） | 有课程目录且当前课时高亮的站点 |
| 4 | 播放中文字标签（“正在播放：xxx”式元素） | 页面明示当前播放内容的站点 |
| 5 | video 元素属性（title/aria-label/data-title） | 播放器把标题写进标签属性 |
| 6 | video 附近标题元素（祖先 5 层内的 title 类/h1-h3） | 播放器容器自带标题 |
| 7 | 页面标题（剥站点名尾巴） | 标题栏含课时名的站点 |

识别结果在录制面板「识别标题」行**实时显示（含来源）**；UUID/长十六进制/长纯数字等无意义名会被自动剔除并落入下一来源，分节文件名最终兜底为「第N节」。**单段模式命名优先级：手动填的文件名 > 识别到的播放标题 > 文件名模板**。若面板显示“未识别到”，用 F12 定位课时名元素：右键课时名 → 检查 → 在元素面板右键该节点 → 复制 → selector，填到设置页「课时名元素选择器」。

## 五、后台录制的重要说明（浏览器限制）

Chrome 对**被完全遮挡或最小化的窗口会停止渲染画面**：此时录制中**声音不断，但画面会冻结在最后一帧**。这不是扩展的缺陷，是浏览器的省电机制。解决：

- **推荐**：使用项目根目录的 `启动录制专用Chrome.bat`——它以关闭遮挡检测的参数启动一个独立 Chrome，窗口随便被盖住都正常录制。首次使用需在其中加载一次扩展（选择 `extension/` 目录）并登录课程网站（见 bat 内说明）
- 通用做法：把播放窗口缩小放到屏幕角落，别最小化、别完全盖住

```bash
# 清单与语法校验
python -c "import json;json.load(open('extension/manifest.json',encoding='utf-8'))"
node --check extension/background.js   # 其余 js 同理逐个检查

# 冒烟测试（自动用 Edge 加载扩展：popup/options 渲染、offscreen 链路、零异常断言）
python scripts/smoke_test.py

# v1.1.0 新链路验证（裁剪上报→会话存储 / 目录控件 / offscreen fsdir）
python scripts/verify_v11.py

# 修改图标后重新生成
python scripts/make_icons.py

# 清理测试残留的浏览器进程
powershell -File scripts/kill_test_chrome.ps1
```

已知测试环境限制：Chrome 稳定版禁用 `--load-extension`，自动化测试走 Edge（同内核，扩展通用）；`/json/list` 里会混入浏览器自带组件扩展，测试脚本已按扩展名强校验。脚本注意事项（踩过的坑）：测试脚本里的路径一律用**正斜杠**（反斜杠路径经某些命令行处理层会把 `\t` 变成 TAB，导致"清单文件丢失"）；测试 profile 启动前自动重建，MV3 Service Worker 空闲 30 秒会停转、需先开个标签页唤醒才能在 CDP 里发现。

## 七、上架 Chrome Web Store checklist

1. 注册 [Chrome Web Store 开发者账号](https://chrome.google.com/webstore/devconsole)（一次性 $5）
2. 打包：把 `extension/` 内所有文件压成 zip（manifest 在根目录）
3. 上传新项 → 填写商店资料（名称/描述/截图 1280×800 至少 1 张、小宣传图 440×280）
4. **隐私声明**（可直接采用，本扩展零数据收集）：
   - 本扩展不收集、不存储、不上传任何用户数据；所有录制内容仅保存在用户本地浏览器下载目录
   - 权限用途：`tabCapture` 录制所选标签页音视频；`offscreen` 在后台文档中维持录制；`downloads` 保存录制文件；`storage` 保存用户设置；`scripting` 在用户点击时向当前页注入"课时标题/播完检测"与"录制区域框选"脚本；`activeTab` 仅在用户点击扩展时临时授权当前标签页（供上述脚本注入，非 host 权限、不常驻）
   - 单一用途描述：录制用户指定的浏览器标签页
5. 注意事项：商店描述中保留"请遵守所访问网站的服务条款"提示
